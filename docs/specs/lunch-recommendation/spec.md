# 오늘 날씨 기반 점심 맛집 추천

`PRODUCT.md`의 핵심 루프 중 그룹 공유·투표를 제외한 개인 추천 단계만 다루는
첫 작업 단위. 그룹 기능 없이도 그 자체로 완결된 사용자 가치를 주고, 한 번에
구현해 실제 동작으로 검증할 수 있는 가장 작은 범위로 좁혔다.

## 사용자 결과

사용자가 서비스를 열면, 오늘의 날씨·계절과 현재 위치를 반영한 주변 음식점
후보 목록을 받는다.

## 승인된 범위

- 개인 사용 흐름만 다룬다. 그룹 공유 링크 생성, 그룹원 열람, 투표는 포함하지
  않는다.
- 위치는 현재 위치 기반 검색만 지원한다. 장소·지역 등록은 포함하지 않는다.
- 음식점 후보는 카카오 로컬 API로 조회한다.
- 날씨 정보는 기상청 단기예보 조회서비스(공공데이터포털)로 조회한다.
- 날씨·계절 조건과 음식 카테고리의 연결은 규칙 기반 매핑으로 처리한다. 외부
  AI 모델 연동은 포함하지 않는다.
- 배달은 대상에서 제외하고, 실제로 가서 먹는 외식만 다룬다(`PRODUCT.md` 경계
  계승).
- 사용자 개인의 취향 프로필은 저장하지 않는다(`PRODUCT.md` 경계 계승).

## 관찰 가능한 수용 기준

- 사용자가 위치 접근을 허용하면, 현재 위치를 기준으로 한 주변 음식점 후보
  목록이 화면에 표시된다.
- 목록의 각 후보는 최소한 상호명, 주소, 카테고리, 현재 위치로부터의 거리를
  보여준다.
- 추천되는 음식 카테고리는 그날의 날씨·계절 조건에 따라 달라진다. 예를 들어
  무더위나 한여름에는 냉면·냉국수 등 시원한 메뉴 카테고리가, 강수가 있는
  날에는 국물·전 요리 카테고리가, 한겨울이나 강추위에는 국밥·찌개 카테고리가
  우선 반영된다.
- 사용자가 위치 접근을 허용하지 않으면, 추천을 볼 수 없는 이유가 화면에
  안내된다.
- 조건에 맞는 음식점이 검색되지 않으면, 그 사실이 화면에 안내된다.

## 확정된 제약과 근거

- **맛집 데이터는 카카오 로컬 API를 쓴다.** 음식점 카테고리(`FD6`) 키워드·
  카테고리 검색을 지원하고, 애플리케이션 등록 후 별도 승인 대기 없이 REST
  API 키를 바로 발급받아 쓸 수 있어 한 번에 구현하고 검증하기에 적합하다.
  응답에는 상호명, 주소(지번·도로명), 좌표, 전화번호, 카카오맵 상세페이지
  URL이 포함되지만 세부 메뉴 정보는 포함되지 않는다.
- **날씨 데이터는 기상청 단기예보 조회서비스를 쓴다.** 공공데이터포털에서
  자동승인으로 신청 즉시 사용할 수 있고 무료이며, 개발 계정 기준 일 10,000건
  한도로 이번 범위에 충분하다. 전국 5km×5km 격자 단위로 초단기실황과
  단기예보(모레까지)를 제공한다.
- **추천 로직은 규칙 기반으로 한다.** AI 모델 연동보다 외부 의존성(추가 API
  키, 비용, 응답 지연 처리)이 적고 결과가 예측 가능해, 한 번에 구현하고
  실제 동작으로 검증하려는 목표에 더 부합한다.
- **그룹 공유·투표는 이번 범위에서 제외한다.** `PRODUCT.md` 핵심 루프의
  개인 추천 단계만 먼저 독립적으로 완성하고 검증하기 위함이다.
- **위치는 현재 위치만 지원한다.** 장소·지역 등록까지 포함하면 한 번에
  구현할 범위를 벗어나므로, 가장 작은 단위로 먼저 검증한다.

## 가정

- 위치는 브라우저의 위치 정보 접근 권한으로 얻는다.
- 음식점 검색 반경은 약 1km로 잡는다.
- 추천 후보는 5~10곳 내외로 보여준다.
- 후보 정렬 기준은 현재 위치로부터의 거리순으로 한다.
- 서비스를 열 때마다 그 시점의 날씨 조건으로 다시 추천한다. 별도의 조회
  횟수 제한은 두지 않는다.
- 날씨·계절 조건과 음식 카테고리를 잇는 규칙은 초기에는 폭염·한파·강수·평시
  등 대표적인 조건 위주로 다루고, 이후 필요에 따라 세분화할 수 있다.

## 범위 밖과 이유

- **그룹 공유 링크 생성, 그룹원 열람, 투표.** `PRODUCT.md` 핵심 루프의 다음
  단계로, 개인 추천이 독립적으로 검증된 뒤 별도 작업 단위로 다룬다.
- **장소·지역 등록.** 현재 위치 기반만으로 첫 범위를 검증하기 위해 제외한다.
- **배달 연동.** `PRODUCT.md`에서 이미 서비스 경계 밖으로 확정됐다.
- **개인 취향 프로필 저장.** `PRODUCT.md`에서 이미 범위 밖으로 확정됐다.

## 미룬 점

- 날씨·계절과 음식 카테고리를 잇는 규칙의 세부 확장(현재는 대표 조건 위주).
- 장소·지역 등록 기능.
- 그룹 공유·투표 기능.

## 남은 위험

- 카카오 로컬 API는 세부 메뉴 정보를 직접 제공하지 않는다. 이후 그룹 공유
  단계에서 `PRODUCT.md`가 요구하는 "후보의 세부 메뉴 확인"을 충족하려면
  추가 데이터 소스나 카카오맵 상세페이지 링크로 대체하는 방안이 필요할 수
  있다.
- 기상청 API는 위경도가 아닌 격자 좌표계를 쓰므로 변환이 필요하고, 격자
  경계 지역에서는 실제 위치와 예보 지점 사이에 약간의 오차가 있을 수 있다.
- 카카오 로컬 API의 정확한 무료 쿼터 수치는 공식 문서에서 로컬 검색에 특정된
  값으로 확인되지 않았다. 애플리케이션을 실제로 등록할 때 재확인이 필요하다.
