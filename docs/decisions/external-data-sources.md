# 외부 데이터 소스

## Decisions

- 음식점(맛집) 후보 데이터는 카카오 로컬 API로 조회한다.
- 날씨 데이터는 기상청 단기예보 조회서비스(공공데이터포털)로 조회한다.

## Boundaries

- 이 결정은 실제 방문 외식 맛집 검색과 당일 날씨 조회에 적용된다. 배달
  서비스 연동이나 예약 기능에는 적용되지 않는다(해당 기능은 `PRODUCT.md`에서
  범위 밖으로 확정됨).
- 카카오 로컬 API는 세부 메뉴 정보를 제공하지 않는다. 메뉴 정보가 필요한
  기능(예: 그룹 공유 시 메뉴 열람)에는 이 API 하나만으로 충분하지 않을 수
  있다.

## Why

두 서비스 모두 애플리케이션·계정 등록 후 별도 승인 대기 없이 즉시 키를
발급받아 쓸 수 있어, "한 번에 구현하고 실제 동작으로 검증"하려는 목표에
부합한다. 카카오 로컬 API는 음식점 카테고리(`FD6`) 키워드·카테고리 검색을
지원하고 상호명·주소·좌표·전화번호·상세페이지 URL을 응답에 포함한다. 기상청
API는 무료이며 자동승인, 개발 계정 기준 일 10,000건 한도로 이번 범위에
충분하고 전국 5km×5km 격자 단위로 초단기실황·단기예보를 제공한다.

## Reconsider when

- 그룹 공유 단계에서 세부 메뉴 정보가 필수 요건이 되어, 카카오 로컬 API만
  으로 충족할 수 없는 경우.
- 두 API의 무료 쿼터·요금 정책이 바뀌어 이번 범위의 사용량을 감당하지 못하게
  되는 경우.
- 서비스 대상 지역이 해외로 확장되어 두 서비스가 커버하지 못하는 지역이
  생기는 경우.

## Still-rejected alternatives

- 네이버 지도/검색 API — 조사 대상에서 카카오 로컬 API로 대체됨; 카카오
  로컬 API가 세부 메뉴를 제공하지 못하는 문제가 실제로 드러나면 재검토.
- Google Places API — 유료 신용카드 등록이 필요해 "한 번에 구현" 목표와
  맞지 않아 제외; 해외 지역 확장이 필요해지면 재검토.
- OpenWeatherMap — 무료 한도(일 1,000건)가 기상청보다 낮고 한국 날씨
  정밀도가 기상청보다 떨어질 수 있어 제외; 기상청 API 쿼터·정책이 이번
  범위를 감당하지 못하게 되면 재검토.

## Evidence worth preserving

- 카카오 로컬 API: 앱 등록 후 즉시 REST API 키 발급, 음식점 카테고리 코드
  `FD6`, 응답에 세부 메뉴 미포함.
  (https://developers.kakao.com/docs/latest/ko/local/dev-guide)
- 기상청 단기예보 조회서비스: 자동승인·무료·개발 계정 일 10,000건,
  5km×5km 격자 단위. (https://www.data.go.kr/data/15084084/openapi.do)
